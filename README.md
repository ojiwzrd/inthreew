# inthreew

inThreew adalah aplikasi pesan anonim yang terinspirasi dari NGL. Pengunjung dapat mengirim pesan tanpa identitas melalui tautan yang dibagikan oleh pengguna. Aplikasi ini dirancang dengan antarmuka yang sederhana, ringan, dan mudah digunakan sehingga siapa pun dapat mengirim pesan secara cepat tanpa perlu membuat akun atau melakukan login.

Setiap pesan yang dikirim akan diproses secara otomatis dan diteruskan ke Telegram Bot yang telah dikonfigurasi. Dengan integrasi ini, pemilik tautan dapat menerima pesan secara real-time langsung melalui Telegram, sehingga lebih praktis untuk mengelola dan membaca pesan yang masuk. Proyek ini dibuat sebagai implementasi layanan pesan anonim berbasis web dengan integrasi Telegram Bot sebagai media notifikasi dan penerimaan pesan.
